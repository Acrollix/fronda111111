# FRONDA for a friend on Mac

Этот вариант нужен не для App Store и не для "идеально доверенного" релиза, а чтобы дать знакомому рабочую FRONDA на Mac.

## Что собирается

- universal macOS build
- `.dmg`
- `.zip`
- без Apple Developer ID
- без notarization

Такой билд подходит для личной передачи знакомому. На первом запуске macOS может попросить открыть приложение вручную через системное подтверждение.

## Локальная сборка на Mac

```bash
npm ci
npm run package:mac:friend
```

Готовые файлы будут в папке `release`.

## Первый запуск у знакомого

Если macOS блокирует запуск:

1. Найти приложение в Finder.
2. Нажать правой кнопкой мыши.
3. Выбрать `Open`.
4. Подтвердить открытие.

После первого подтверждения приложение обычно открывается дальше как обычное локально доверенное приложение для этого Mac.

## Ограничение

Этот вариант не заменяет signed/notarized релиз.
Если нужно, чтобы приложение открывалось без предупреждений вообще на любом Mac, тогда уже потребуется Apple Developer ID и notarization.
