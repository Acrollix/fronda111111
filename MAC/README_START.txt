FRONDA Portable Desktop App

Быстрый старт
1. Распакуйте эту папку в любое место вне общей папки с данными Яндекс Диска.
2. Запустите FRONDA.exe.
3. Пройдите мастер первого запуска.
4. Укажите локально синхронизированную общую папку данных FRONDA.
5. Дождитесь построения локального кэша и открытия рабочего пространства.

Важные правила
- Не размещайте папку приложения внутри общей папки с данными.
- Не редактируйте JSON-файлы общего набора вручную, пока запущено приложение.
- Приложение работает только с локальной синхронизированной папкой и не использует API Яндекс Диска.
- Локальный кэш, журналы, черновики и локальные резервные копии хранятся в PortableData рядом с приложением.

Примечания по сборке
- Эта сборка автономна и не требует отдельной установки Python, Node.js, WebView или сервера базы данных.
- Если Git настроен, FRONDA может экспортировать снимки в локальный git-репозиторий, но Git не обязателен для работы.
